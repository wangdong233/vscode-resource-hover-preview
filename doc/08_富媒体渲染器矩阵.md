# 08 — 富媒体渲染器矩阵（v0.2 - v0.5 路线图）

> 本文档从 [03](03_浮动预览弹窗设计.md) 拆出。03 只管**弹窗骨架 + 图片渲染（v0.1 MVP）**；本篇管 v0.2+ 的视频/音频/字体/PDF/3D 五类渲染器。

## 0. CSP 事实基线（实测 VSCode 1.129.1 stable，2026-08-08 白盒读 workbench.html）

> 本节是所有渲染器的 CSP 前提，单源落点。完整 CSP meta 在 `out/vs/code/electron-browser/workbench/workbench.html`。

生产 CSP 关键指令（精确串）：
```
default-src 'none';
img-src 'self' data: blob: vscode-remote-resource: vscode-managed-remote-resource: https:;
media-src 'self';
script-src 'self' 'unsafe-eval' blob:;
style-src 'self' 'unsafe-inline';
connect-src 'self' https: ws:;
font-src 'self' vscode-remote-resource: vscode-managed-remote-resource: https://*.vscode-unpkg.net;
require-trusted-types-for 'script';
trusted-types <23 个 VSCode 内部 policy，项目不可用>;
```

**对渲染器的逐指令影响（推导 + 实证）**：
- **无 `worker-src`、无 `child-src`** → 按 CSP3 规范回退链 `worker-src → child-src → script-src → default-src`，**最终落到 `script-src 'self' 'unsafe-eval' blob:`**。后果：blob: worker ✅ / 同源(vscode-file) worker ✅ / `http://127.0.0.1` worker ❌。→ pdf.js/three.js worker 必须走 **blob URL**，不能直连 EH。
- **`script-src` 无 `http://127.0.0.1`** → 动态 `import('http://127.0.0.1/.../pdf.mjs')` 被 CSP 拦（import() 受 script-src 管）。→ 重库必须 **fetch(connect-src 已 patch) → Blob → import(blobUrl)**，blob: 在 script-src 内 ✅。
- **`'unsafe-eval'` 已在 script-src** → pdf.js 的 `Function()` 字体优化 ✅（`isEvalSupported` 默认 true 可留）。
- **`media-src` 仅 `'self'`** → video/audio 的 http src 必须 patch 加 `http://127.0.0.1:* blob:`（[02 patchCsp](02_workbench注入设计.md#csp-patch完整规格)）。
- **`font-src` 严苛但无关** → FontFace 用 **ArrayBuffer 源**（非 URL 源）不经网络，完全绕开 font-src ✅。URL 源才会被 font-src 拦（不用）。
- **blob: 已在 script-src** → `createElement('script')+src=blobUrl` 与 `import(blobUrl)` 都 ✅；这是重库加载的支点。

**patch 三件保持不变**（[02](02_workbench注入设计.md)）：connect-src / img-src / media-src 各加 `http://127.0.0.1:*`，media-src 再加 `blob:`。**不碰 script-src / worker-src / font-src**——blob 回退 + ArrayBuffer 源让我们免动这三个最敏感指令。

## 1. video（v0.2）——直 HTTP src + 原生 Range seek

> **修正**（参考 VSCode 内置 media-preview videoPreview.js 做法）：原草案 `fetch→blob→createObjectURL→video.src` 把整文件读进内存，破坏流式、浪费内存、seek 大文件必重下。改用 **直接 HTTP src**，让浏览器 `<video>` 元素自己向 `serveStream` 发 Range 请求（[04 serveStream](04_EH与Renderer通信协议.md) 已实现 206）。

```javascript
function renderVideo(filePath) {
    const content = document.querySelector('.mp-content');
    const video = document.createElement('video');
    // 直 HTTP src：浏览器原生 Range seek，不经 blob，不预读全文
    video.src = `${SERVER_BASE}/preview?file=${encodeURIComponent(filePath)}&type=video&token=${TOKEN}`;
    video.controls = true;
    video.autoplay = true;
    video.muted = true;        // muted 才大概率允许非用户手势 autoplay（同 media-preview）
    video.playsInline = true;  // 同 media-preview，避免移动端全屏
    video.style.maxWidth = '100%'; video.style.maxHeight = '100%';
    content.replaceChildren(video);  // createElement，不走 innerHTML（TT）
    // 生命周期：hidePopup 时 content.replaceChildren() 即移除 video，浏览器停 Range 流，无需 revokeObjectURL（非 blob src）
}
```
- **autoplay 策略**（同 media-preview videoPreview.js）：`autoplay = settings.autoplay; muted = settings.autoplay`——即「要 autoplay 就必须 muted」配对。Chromium 对 muted+非用户手势放行率高；若仍被拦，监听 `video.play()` rejected → UI 提示「点击播放」(showPlayButton)，不静默失败。
- **加载完成检测**：监听 `canplaythrough`（同 media-preview）切换 loading→ready 态；监听 `error` 切 error 态。
- **EH serveStream Range 硬化**（[04](04_EH与Renderer通信协议.md) 已给）：clamp `end=fileSize-1`、`/^bytes=(\d+)-(\d*)$/` 严格校验、`start>end||start>=size` 返 416、必须返 `Accept-Ranges: bytes`。
- **CSP**：`<video>` http src 受 `media-src` 管 → [02](02_workbench注入设计.md) patch `media-src` 加 `http://127.0.0.1:* blob:`（blob: 备用，直 src 走 http）。

## 2. audio（v0.3，波形砍）

- **范围**：只做 `<audio>` 原始流预览（复用 video 的直 HTTP src + serveStream range 路径）。参考 media-preview audioPreview.js 用 `new Audio(src)`。
```javascript
function renderAudio(filePath) {
    const content = document.querySelector('.mp-content');
    const audio = document.createElement('audio');  // 等价 new Audio()
    audio.src = `${SERVER_BASE}/preview?file=${encodeURIComponent(filePath)}&type=audio&token=${TOKEN}`;
    audio.controls = true;
    audio.style.width = '100%';
    content.replaceChildren(audio);  // createElement（TT）
    audio.addEventListener('canplaythrough', () => {/* ready 态 */});
}
```
- **波形 NO-GO**：见 [11 F2](11_rejected-by-design清单.md)。`ffmpeg.wasm` 需 COOP/COEP（workbench 没有）；系统 ffmpeg 捆绑过重。
- **v1.0+ 复活路径**：纯 JS `AudioContext.decodeAudioData` 解码 PCM 画波形（免 ffmpeg，仅限浏览器可解码格式 mp3/wav/ogg）。

## 3. font（v0.3）——FontFace ArrayBuffer 源，免 CSP patch

- **优先 FontFace API**（免 opentype.js ~150KB 体积）。关键：用 **ArrayBuffer 源**（非 URL 源），完全绕开 `font-src` CSP（无网络请求）。
```javascript
async function renderFont(filePath) {
    const resp = await fetch(`${SERVER_BASE}/preview?file=${encodeURIComponent(filePath)}&type=font&token=${TOKEN}`);
    const buf = await resp.arrayBuffer();  // connect-src 已 patch
    const face = new FontFace('MpPreviewFont', buf);  // ArrayBuffer 源 → 不经 font-src
    await face.load();
    document.fonts.add(face);
    // canvas 绘样本 glyph grid（多字号 pangram，纯 canvas，TT 安全）
    const canvas = document.createElement('canvas');
    canvas.width = popupW; canvas.height = popupH;
    const ctx = canvas.getContext('2d');
    const samples = [
        { size: 48, text: 'The quick brown fox' },
        { size: 24, text: 'ABCDEFGabcdefg 0123456789' },
        { size: 14, text: '!@#$%^&*()_+-={}[]|;:\'<>,./?~`' }
    ];
    let y = 0;
    for (const s of samples) {
        ctx.font = `${s.size}px MpPreviewFont`;
        ctx.fillText(s.text, 20, y += s.size + 8);
    }
    document.querySelector('.mp-content').replaceChildren(canvas);
    // 生命周期：hidePopup 时 document.fonts.delete(face) + face.unload() 防字体表累积
}
```
- **格式**：v0.3 支持 ttf/otf/woff/woff2。**woff2 经 FontFace 原生解码**——Chromium/Electron 内置 Brotli 解压 + woff2 解码器（默认启用，关闭需 enterprise policy，VSCode 不会关）。FontFace 对四种格式统一处理，无分支代码。Spike 7 末步实测一个 .woff2 确认。
- **v1.0+ opentype.js 路径**：仅当需「glyph 覆盖图（cmap 表里有哪些字形）/kerning 表/轮廓矢量化」时才引入 opentype.js（~150KB）。v0.3 的「样本字符渲染」用 FontFace + canvas 按码点 `String.fromCodePoint(i)` 扫一段即可，够用。
- **DOM 全程 createElement**（TT）。canvas 绘字纯 API 无 DOM 注入。
- **EH serveFont** 返回 base64（[04](04_EH与Renderer通信协议.md)），overlay `atob→Uint8Array→ArrayBuffer` 喂 FontFace；或 EH 直接返二进制 stream（更省内存），overlay `resp.arrayBuffer()`。

## 6. 重库通用 lazy loader（ESM blob 加载器）

> pdf.js v6 / three.js r185 均为 **ES Module only**（UMD 已废），且 workbench 非模块上下文 + script-src 不含 `http://127.0.0.1` + TT 禁 innerHTML。统一用 **fetch→Blob→dynamic import(blobUrl)** 加载。blob 同源 + script-src 已含 `blob:` → 合规，且不碰 script-src/worker-src/font-src。

```javascript
// 通用：fetch JS 源码 → blob URL（一次性，缓存复用）
const _libCache = new Map();  // name → module namespace
async function loadLibBlob(name, libPath) {
    if (_libCache.has(name)) return _libCache.get(name);
    const resp = await fetch(`${SERVER_BASE}/lib/${libPath}?token=${TOKEN}`);  // connect-src 已 patch
    if (!resp.ok) throw new Error(`load ${name} failed: ${resp.status}`);
    const code = await resp.text();
    const blob = new Blob([code], { type: 'text/javascript' });
    const url = URL.createObjectURL(blob);
    const mod = await import(url);          // blob 同源 → import() 受 script-src，blob: ✅
    URL.revokeObjectURL(url);               // 已 import 到内存，URL 可释放
    _libCache.set(name, mod);
    return mod;
}
// 通用：fetch worker 源码 → blob URL（不 revoke，worker 持续用）
async function makeBlobWorkerUrl(libPath) {
    const resp = await fetch(`${SERVER_BASE}/lib/${libPath}?token=${TOKEN}`);
    const code = await resp.text();
    return URL.createObjectURL(new Blob([code], { type: 'text/javascript' }));
}
```
- **为何不用 `appendChild(<script src>)`**：①pdfjs-dist v6 是 `.mjs`，经典 `<script>` 标签加载模块文件抛 SyntaxError；②`http://127.0.0.1` 不在 script-src，静态/运行时 cross-origin script 都被拦；③TT 下 `createElement('script').src=blobUrl` 虽可（非 TT sink），但模块暴露要靠 globalThis 赋值，不如 import() 干净返 namespace。
- **/lib 端点**（[04](04_EH与Renderer通信协议.md)）：EH `GET /lib/:name` 返回对应 JS 文件（pdf.js/three bundle 从扩展 `resources/lib/` 读）。
- **首次加载耗时**：pdf.min.mjs 455KB + worker 1.26MB → 首个 PDF 悬停有 1-3s 延迟，popup 显 loading；加载后 `_libCache` 常驻到进程结束（合理：用户会预览多个文件）。

## 4. pdf（v0.4，前置 Spike 7）——blob ESM 加载，无 text-layer TT 问题

> **修正三处旧假设**（实证 2026-08-08）：
> 1. pdfjs-dist **v6 是 ESM-only**（`.mjs`），无 legacy UMD。原 `<script src=./lib/pdf.min.js>` 经典标签加载会抛 SyntaxError。改 blob + dynamic import。
> 2. **「关 text layer 绕 TT」是误解**：①现代 pdf.js `src/display/text_layer.js` 全用 `createElement`/`textContent`（源码确证，0 处 innerHTML）；②本渲染只调 `page.render({canvasContext, viewport})` 画 canvas 位图，**从不实例化 TextLayer**，根本没有 text layer DOM。`renderTextLayer` 也非 pdf.js 真实 option。→ TT 对 pdf.js 不是问题，Spike 7 该判据删除。
> 3. **worker 必须是 blob**（不是 http）：worker-src 回退到 script-src，`http://127.0.0.1` 不在内 → 跨域 module worker 被拦。用 blob worker（blob: 在 script-src ✅）。`pdf.worker.min.mjs` 实测 0 处 import，自包含，blob module worker 可行。

```javascript
let pdfjsLib = null;
async function ensurePdfjs() {
    if (pdfjsLib) return pdfjsLib;
    pdfjsLib = await loadLibBlob('pdfjs', 'pdf.min.mjs');  // §6
    pdfjsLib.GlobalWorkerOptions.workerSrc = await makeBlobWorkerUrl('pdf.worker.min.mjs');
    return pdfjsLib;
}

async function renderPdf(filePath) {
    const lib = await ensurePdfjs();
    const resp = await fetch(`${SERVER_BASE}/preview?file=${encodeURIComponent(filePath)}&type=pdf&token=${TOKEN}`);
    const ab = await resp.arrayBuffer();
    const pdf = await lib.getDocument({
        data: ab,
        isEvalSupported: true,   // unsafe-eval 已在 script-src，字体优化开
        // 不传 renderTextLayer/不存在该 option；只画 canvas
    }).promise;
    const page = await pdf.getPage(1);
    const canvas = document.createElement('canvas');
    const dpr = window.devicePixelRatio || 1;
    const viewport = page.getViewport({ scale: 1.0 });
    const fit = Math.min((popupW - 20) / viewport.width, (popupH - 20) / viewport.height, 1.5);
    const vp2 = page.getViewport({ scale: fit * dpr });
    canvas.width = vp2.width; canvas.height = vp2.height;
    canvas.style.width = (vp2.width / dpr) + 'px'; canvas.style.height = (vp2.height / dpr) + 'px';
    await page.render({ canvasContext: canvas.getContext('2d'), viewport: vp2 }).promise;
    document.querySelector('.mp-content').replaceChildren(canvas);
    // dispose: hidePopup 时 await pdf.destroy() 释放 worker + 内存；canvas replaceChildren 自动移除
}
```
- **EH 打包**：`resources/lib/pdf.min.mjs` + `pdf.worker.min.mjs`（pdfjs-dist v6.2+ build/ 目录两文件，复制即可，无需重新打包——两文件均自包含）。
- **生命周期**：`loadingTask.destroy()` / `pdf.destroy()` 释放 worker transport 与字体；popup 切换必调。
- **Spike 7 判据修订**（[10](10_风险登记册与spike验证.md)）：去掉「关 text layer 绕 TT」「eval 检查」；保留并强化「blob worker 可创建 + getDocument 渲染首页 canvas 成功」。

## 5. 3D（v0.5，前置 Spike 7）——构建时 bundle + forceContextLoss + 事件分层

> **修正**：three.js r185 **无 UMD build**（`build/three.min.js` 已 404 删除），核心 `three.module.min.js` 自包含但 OrbitControls/GLTFLoader 是独立 ES module 且 `import { ... } from 'three'` 裸说明符——blob 加载无法解析裸 import。→ **必须构建时 esbuild bundle 成单文件**（pdf.js 不用，three 要）。

**构建步骤（一次性，入扩展构建脚本）**：
```bash
# 打包 three 核心 + OrbitControls + GLTFLoader 为单 IIFE，暴露 globalThis.MP_THREE
esbuild entry-three.js --bundle --format=iife --outfile=resources/lib/mp-three.bundle.js
```
```javascript
// entry-three.js（扩展源码，仅构建用，不进 overlay）
import * as THREE from 'three';
import { OrbitControls } from 'three/examples/jsm/controls/OrbitControls.js';
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js';
globalThis.MP_THREE = { ...THREE, OrbitControls, GLTFLoader };
```

```javascript
let threeReady = null;  // {renderer,controls,rafId,scene,cleanup}
async function ensureThree() {
    if (window.MP_THREE) return window.MP_THREE;
    const mod = await loadLibBlob('three', 'mp-three.bundle.js');  // §6；IIFE 也走 import(blobUrl)
    return window.MP_THREE || mod;
}

async function render3D(filePath) {
    const T = await ensureThree();
    const content = document.querySelector('.mp-content');
    const canvas = document.createElement('canvas');
    canvas.style.width = '100%'; canvas.style.height = '100%';
    content.replaceChildren(canvas);

    const scene = new T.Scene();
    const camera = new T.PerspectiveCamera(45, canvas.clientWidth/canvas.clientHeight, 0.1, 1000);
    const renderer = new T.WebGLRenderer({ canvas, antialias: true });
    renderer.setSize(canvas.clientWidth, canvas.clientHeight, false);
    const controls = new T.OrbitControls(camera, canvas);  // 绑定 canvas，非 popup

    const resp = await fetch(`${SERVER_BASE}/preview?file=${encodeURIComponent(filePath)}&type=3d&token=${TOKEN}`);
    const ab = await resp.arrayBuffer();
    const gltf = await new T.GLTFLoader().parseAsync(ab, '');
    scene.add(gltf.scene);

    let rafId;
    (function animate(){ rafId = requestAnimationFrame(animate); controls.update(); renderer.render(scene, camera); })();

    const cleanup = makeDisposeGLTF(gltf.scene);  // 见 dispose3D
    threeReady = { renderer, controls, rafId, cleanup };
}

function dispose3D() {
    if (!threeReady) return;
    const { renderer, controls, rafId, cleanup } = threeReady;
    cancelAnimationFrame(rafId);
    controls.dispose();           // 移除 canvas 上 pointerdown/wheel/contextmenu + document keydown（实证源码 disconnect）
    cleanup();                    // 遍历 dispose geometry/material/texture
    renderer.dispose();           // 清内部 cache（renderLists/programCache...）
    renderer.forceContextLoss();  // ★ 关键：真正释放 WebGL context，否则累积超 ~16 个 context 必崩
    threeReady = null;
}

// GLTFLoader 无内置 dispose，必须遍历（three.js 官方范式）
function makeDisposeGLTF(scene) {
    const disposables = [];
    scene.traverse(o => {
        if (o.geometry) disposables.push(o.geometry);
        if (o.material) (Array.isArray(o.material) ? o.material : [o.material]).forEach(m => {
            for (const k in m) { const v = m[k]; if (v && v.isTexture) disposables.push(v); }
            disposables.push(m);
        });
    });
    return () => disposables.forEach(d => d.dispose());
}
```
- **事件分层**（实证 OrbitControls.js connect/dispose L495-535，与 [03 四角缩放](03_浮动预览弹窗设计.md#四角缩放) 互不干扰）：OrbitControls 只在 **canvas** 上绑 pointerdown/wheel/contextmenu；popup 四角 handle 是 canvas 的**兄弟元素**且 z-index 更高，handle 的 mousedown `stopPropagation` 后事件冒泡到 popup→body，**永不到达 canvas**（兄弟不互传）。→ 拖 handle 缩放不会触发模型旋转，反之亦然。无需额外处理，[03](03_浮动预览弹窗设计.md) 现有 stopPropagation 即正确。
- **一个权衡点**：OrbitControls 的 wheel 是 `passive:false`（缩放模型），悬停 canvas 时滚轮缩放模型而非滚 popup——这是 3D 预期的、正确的行为。
- **GLTFLoader 依赖**：若 .glb 用了 Draco/KTX2 压缩，需额外传 DRACOLoader/KTX2Loader（各自也是 ES module，进同一 bundle）。v0.5 MVP 先支持未压缩 glb/gltf，压缩格式推迟并按需加 decoder。

## 渲染器 dispatch（overlay 侧）——补生命周期清理钩子

```javascript
const RENDERERS = {
    image: renderImage,    // [03](03_浮动预览弹窗设计.md)
    video: renderVideo,
    audio: renderAudio,
    font: renderFont,
    pdf: renderPdf,
    '3d': render3D,
};

async function renderByType(type, filePath) {
    const fn = RENDERERS[type];
    if (!fn) { showPopupError('unsupported type'); return; }
    try {
        // 每次渲染前先清上一类型资源（防切类型时旧资源泄漏，R-INT-07 运行时态）
        disposeActiveRenderer();
        await fn(filePath);
        activeRendererType = type;
    } catch (e) {
        showPopupError(e.message);  // 文件不存在/过大/server 无响应/库加载失败
    }
}

let activeRendererType = null;
function disposeActiveRenderer() {
    // 3D 有专门 dispose；video/audio/font 的清理由各自 replaceChildren/face.unload 处理
    if (activeRendererType === '3d') dispose3D();
    // （可扩展：pdf 可 await pdf.destroy()，需登记 loadingTask）
    activeRendererType = null;
}
```

> **类型支持矩阵单源**不变：见 [04 /config 端点](04_EH与Renderer通信协议.md#config端点)（EH 返回 type→mime，overlay 启动 fetch，不硬编码 MEDIA_TYPES，R-INT-02）。
