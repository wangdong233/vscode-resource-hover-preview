# 05 — 三平台路径与权限（路径权威落点）

> 本文档是 **VSCode 安装路径与 workbench.html 定位的单一真相源**。[01](01_自愈patch机制设计.md)/[02](02_workbench注入设计.md) 的路径均引用此处，不内联复述（消除三处漂移风险，R-CI-01）。

## VSCode 安装路径定位（app 目录）

### macOS

| Flavor | app 目录 | 资源目录（含 workbench.html） |
|--------|----------|------------------------------|
| VSCode | `/Applications/Visual Studio Code.app/Contents/Resources/app` | `.../app/out/vs/code/electron-browser/workbench/workbench*.html`（Spike 3 实测 1.129.1；多候选见下） |
| Insiders | `/Applications/Visual Studio Code - Insiders.app/Contents/Resources/app` | 同上 |
| VSCodium | `/Applications/VSCodium.app/Contents/Resources/app` | 同上 |
| Cursor | `/Applications/Cursor.app/Contents/Resources/app` | 同目录，但 HTML 名可能是 `workbench-apc-extension.html`（experimental） |

**product.json**: `.../app/product.json`

```typescript
function findVscodeOnMac(): string[] {
    const found: string[] = [];
    const apps = [
        "/Applications/Visual Studio Code.app",
        "/Applications/Visual Studio Code - Insiders.app",
        "/Applications/VSCodium.app",
        "/Applications/Cursor.app",
    ];
    const homeApps = apps.map(p => p.replace("/Applications/", path.join(os.homedir(), "Applications/") + "/"));
    for (const app of [...apps, ...homeApps]) {
        const resDir = path.join(app, "Contents", "Resources", "app");
        if (fs.existsSync(path.join(resDir, "product.json"))) found.push(resDir);
    }
    return found;
}
```

### Windows

| Flavor | app 目录 |
|--------|----------|
| VSCode (User) | `C:\Users\<user>\AppData\Local\Programs\Microsoft VS Code\resources\app` |
| VSCode (System) | `C:\Program Files\Microsoft VS Code\resources\app` |
| Insiders | `C:\Users\<user>\AppData\Local\Programs\Microsoft VS Code Insiders\resources\app` |
| VSCodium | `C:\Users\<user>\AppData\Local\Programs\VSCodium\resources\app` |

```typescript
function findVscodeOnWindows(): string[] {
    const found: string[] = [];
    const home = process.env.LOCALAPPDATA || path.join(os.homedir(), "AppData", "Local");
    const candidates = [
        path.join(home, "Programs", "Microsoft VS Code", "resources", "app"),
        path.join("C:", "Program Files", "Microsoft VS Code", "resources", "app"),
        path.join(home, "Programs", "Microsoft VS Code Insiders", "resources", "app"),
        path.join(home, "Programs", "VSCodium", "resources", "app"),
    ];
    for (const dir of candidates) if (fs.existsSync(path.join(dir, "product.json"))) found.push(dir);
    return found;
}
```

### Linux

| Flavor | app 目录 |
|--------|----------|
| VSCode (deb/rpm) | `/usr/share/code/resources/app` 或 `/usr/share/vscode/resources/app` |
| VSCode (tarball) | `/opt/VSCode/resources/app` |
| Insiders | `/usr/share/code-insiders/resources/app` |
| VSCodium | `/usr/share/vscodium/resources/app` 或 `/opt/vscodium/resources/app` |
| Snap | `/snap/code/current/usr/share/code/resources/app` ⚠️ 只读 squashfs，见下 |
| ~~Flatpak~~ | **不支持**（沙箱禁止写宿主，[11 P1](11_rejected-by-design清单.md)） |

```typescript
function findVscodeOnLinux(): string[] {
    const found: string[] = [];
    const candidates = [
        "/usr/share/code/resources/app",
        "/usr/share/vscode/resources/app",
        "/opt/VSCode/resources/app",
        "/usr/share/code-insiders/resources/app",
        "/usr/share/vscodium/resources/app",
        "/opt/vscodium/resources/app",
        "/snap/code/current/usr/share/code/resources/app",
    ];
    for (const dir of candidates) if (fs.existsSync(path.join(dir, "product.json"))) found.push(dir);
    return found;
}
```

## 统一发现函数

```typescript
function discoverVscodeInstalls(): string[] {
    switch (process.platform) {
        case "darwin": return findVscodeOnMac();
        case "win32":  return findVscodeOnWindows();
        case "linux":  return findVscodeOnLinux();
        default:       return [];
    }
}
```

## workbench.html 精确路径（多候选，不靠 glob 碰运气）

> ⚠️ [10 Spike 3](10_风险登记册与spike验证.md)：`workbench.esm.html` vs `workbench.html`、`electron-sandbox` vs `electron-browser` 两轴歧义（vscode-custom-css 源码注释与官方博客矛盾）。~~VSCode 1.70 还移除了 `workbench.js`~~ **修正（Spike 3 实测 1.129.1）：workbench.js 仍存在（30882 字节，被 `<script src="./workbench.js" type="module">` 引用），未移除**。**patcher 用有序候选数组，首个命中即用**。

```typescript
// 有序候选（顺序据 2026-08-08 实证调整：1.129.1 stable 命中 electron-browser/workbench.html）
const WORKBENCH_CANDIDATES = [
    "out/vs/code/electron-browser/workbench/workbench.html",       // ✅ 实证命中(1.129.1 stable)
    "out/vs/code/electron-sandbox/workbench/workbench.esm.html",   // 官方博客称现行(与实证矛盾,并列保留)
    "out/vs/code/electron-sandbox/workbench/workbench.html",
    "out/vs/code/electron-browser/workbench/workbench.esm.html",
    "out/vs/code/electron-sandbox/workbench/workbench-apc-extension.html", // Cursor fork
];

function findWorkbenchHtml(appDir: string): string | null {
    for (const rel of WORKBENCH_CANDIDATES) {
        const p = path.join(appDir, rel);
        if (fs.existsSync(p)) return p;
    }
    // glob 兜底（最后手段，不作为主路径）
    const matches = glob.sync("out/vs/code/**/workbench*.html", { cwd: appDir });
    return matches.length > 0 ? path.join(appDir, matches[0]) : null;
}
```

> **动手前必做 [Spike 3](10_风险登记册与spike验证.md)**：本机 `find` 确认目标版本实际命中哪个候选，据此调整候选顺序。

## 权限处理

### macOS

`/Applications/` 目录的 app 文件通常**当前用户可写**（macOS 不强制 root）。验证：`fs.accessSync(workbenchHtmlPath, fs.constants.W_OK)`。

**若不可写**（MDM 管理等少见）：提示 `sudo npx vscode-media-preview@latest`。

**⚠️ 代码签名（[10 Spike 5](10_风险登记册与spike验证.md)，cc-status-dot 不存在的新失败）**：改 `.app` 内文件 invalidate Apple 代码签名。Gatekeeper 对未清 quarantine 的 app 可能弹"已损坏/无法验证开发者"。
- **Spike 验证**：patch 后重启 VSCode 观察是否弹签名警告。
- **预案**：若触发，文档补 `codesign --remove-signature "/Applications/Visual Studio Code.app"` 或 ad-hoc 重签：
  ```bash
  sudo codesign --force --deep --sign - "/Applications/Visual Studio Code.app"
  ```

### Windows

`%LOCALAPPDATA%\Programs\` 用户可写（不需 admin）。`C:\Program Files\` 需管理员（提示用户用管理员终端）。

### Linux

`/usr/share/` 通常需 sudo：提示 `sudo npx vscode-media-preview@latest`。

**Snap**：squashfs 通常只读 → patch 不了。需 Spike 确认；若不可写，README 标"不支持 Snap"（[11 P2](11_rejected-by-design清单.md)）。

## 支持矩阵（README 同步）

| Flavor | 支持度 | 说明 |
|---|---|---|
| VSCode (macOS/Win-User/Linux-tarball) | ✅ 完整 | 用户可写，主测试平台 |
| VSCode Insiders | ✅ | 同 VSCode |
| VSCodium | ✅ | 同路径模式 |
| VSCode Win-System / Linux-deb | ⚠️ 需提权 | 管理员/sudo 终端跑 npx |
| Cursor | 🧪 experimental | HTML 名不同（apc-extension），未验证 |
| Snap | ❓ 待 Spike | squashfs 只读，可能不支持 |
| Flatpak | ❌ 不支持 | 沙箱禁写宿主（[11 P1](11_rejected-by-design清单.md)） |

## patch 后验证（每平台）

1. `fs.existsSync(workbenchHtmlPath)` → 确认文件在。
2. 读回确认注入标记 `<!--mp-injected:...-->` 在。
3. `JSON.parse(product.json)` → JSON 格式没破坏。
4. `fs.existsSync(overlayJsPath)` → overlay.js 在。
5. macOS：首次重启观察是否弹签名警告（Spike 5）。
