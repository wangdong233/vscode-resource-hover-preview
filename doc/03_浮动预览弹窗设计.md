# 03 — 浮动预览弹窗设计（v0.1 MVP：骨架 + 图片渲染）

> 本文档只管**弹窗骨架 + 图片渲染（v0.1 MVP）**。video/audio/font/pdf/3d 渲染器见 [08 富媒体矩阵](08_富媒体渲染器矩阵.md)。
>
> **v0.1 交互定调**（用户决策 2026-08-08）：浮动弹窗 + **四角缩放** + **智能四象限定位** + 尺寸记忆。**不做自由位置拖拽**（[11 F1](11_rejected-by-design清单.md)）。

## 概述

overlay.js(IIFE) 在 VSCode Renderer(Chromium) 运行：
1. 监听鼠标悬停 Explorer 文件项（event delegation，[06](06_DOM选择器容错策略.md)）。
2. 判断是否媒体文件（类型表单源见 [04 /config](04_EH与Renderer通信协议.md#config端点)）。
3. **智能四象限定位**显示浮动 popup（位置固定，按文件项位置自适应）。
4. 四角可缩放 + 尺寸记忆。
5. 从 EH localhost server 获取预览内容。

## 核心流程

```
用户鼠标进入 Explorer 文件项(event delegation 冒泡)
  → 延迟 300ms(HOVER_DELAY 防抖)
  → resolveFilePath(filename)([06](06_DOM选择器容错策略.md))
  → detectMediaType(filename) → 非媒体 → 取消
  → 创建/复用 popup + 四象限定位(按文件项 rect)
  → fetch /preview → 渲染(createElement，TT 安全)
  → 显示 popup

用户鼠标离开文件项(且不在 popup 内)
  → 延迟 200ms(HIDE_DELAY)
  → (非 pinned) → hidePopup + dispose 渲染资源
```

## Popup DOM 结构（createElement 构建，TT 安全）

> ⚠️ **禁用 `innerHTML`**（[10 Spike 1](10_风险登记册与spike验证.md)）：workbench 强制 `require-trusted-types-for 'script'`，`innerHTML` 字符串赋值被拦。全程 `createElement`。

```javascript
// 一次性创建 popup 骨架（复用，不重建）
function ensurePopup() {
    let popup = document.getElementById('mp-popup');
    if (popup) return popup;
    popup = document.createElement('div');
    popup.id = 'mp-popup';

    const toolbar = document.createElement('div');
    toolbar.className = 'mp-toolbar';
    const fname = document.createElement('span'); fname.className = 'mp-fname';
    const ftype = document.createElement('span'); ftype.className = 'mp-type';
    const pinBtn = document.createElement('button'); pinBtn.className = 'mp-pin'; pinBtn.textContent = '📌';
    const closeBtn = document.createElement('button'); closeBtn.className = 'mp-close'; closeBtn.textContent = '✕';
    toolbar.append(fname, ftype, pinBtn, closeBtn);

    const content = document.createElement('div'); content.className = 'mp-content';

    // 四角 resize handle
    const corners = ['nw', 'ne', 'sw', 'se'];
    const handles = corners.map(c => {
        const h = document.createElement('div');
        h.className = `mp-resize mp-resize-${c}`;
        h.dataset.corner = c;
        return h;
    });

    popup.append(toolbar, content, ...handles);
    document.body.appendChild(popup);
    bindPopupInteractions(popup);   // 缩放/pin/close
    loadPopupSize(popup);           // 尺寸记忆
    return popup;
}
```

## 四象限智能定位（核心，替代自由拖拽）

> **设计意图**：位置不跟随鼠标自由移动，而是按**悬停文件项在视口的位置**，自动选四个展开方向之一，使 popup 朝视口空旷侧展开、避开文件项本身与屏幕边缘。定位可预测、不遮挡、无需用户手动挪。

```javascript
/**
 * 按文件项 rect 决定 popup 展开象限并定位。
 * @param itemRect 悬停文件项的 getBoundingClientRect()
 *
 * 决策：以文件项中心相对视口中心的偏移定象限：
 *   文件项中心在视口 左+上 → popup 展在文件项「右下」（向右下展开，NW 角锚定文件项右下角附近）
 *   文件项中心在视口 右+上 → popup 展在文件项「左下」（向左下展开，NE 角锚定）
 *   文件项中心在视口 左+下 → popup 展在文件项「右上」（向右上展开，SW 角锚定）
 *   文件项中心在视口 右+下 → popup 展在文件项「左上」（向左上展开，SE 角锚定）
 * 即 popup 总朝视口中心方向展开，避开文件项与边缘。
 */
function placePopup(itemRect) {
    const popup = ensurePopup();
    const vw = window.innerWidth, vh = window.innerHeight;
    const GAP = 12;                          // 与文件项的间距
    const itemCenterX = itemRect.left + itemRect.width / 2;
    const itemCenterY = itemRect.top + itemRect.height / 2;

    // 先让 popup 按记忆尺寸排版，量实际宽高
    const w = popup.offsetWidth, h = popup.offsetHeight;

    let x, y;
    if (itemCenterX < vw / 2 && itemCenterY < vh / 2) {
        // 文件项在左上 → popup 右下展开
        x = itemRect.right + GAP;  y = itemRect.bottom + GAP;
    } else if (itemCenterX >= vw / 2 && itemCenterY < vh / 2) {
        // 文件项在右上 → popup 左下展开
        x = itemRect.left - GAP - w;  y = itemRect.bottom + GAP;
    } else if (itemCenterX < vw / 2 && itemCenterY >= vh / 2) {
        // 文件项在左下 → popup 右上展开
        x = itemRect.right + GAP;  y = itemRect.top - GAP - h;
    } else {
        // 文件项在右下 → popup 左上展开
        x = itemRect.left - GAP - w;  y = itemRect.top - GAP - h;
    }

    // 边界保护：超出视口则贴边（不让 popup 跑出屏幕）
    x = Math.max(8, Math.min(x, vw - w - 8));
    y = Math.max(8, Math.min(y, vh - h - 8));

    popup.style.left = x + 'px';
    popup.style.top = y + 'px';
}
```

> **触发时机**：用 mouseover 委托拿到目标文件项元素后，`placePopup(target.getBoundingClientRect())`。位置在 hover 触发时一次性确定，hover 期间不跟随鼠标移动（位置固定）。

## 四角缩放（4 个 handle，对角固定）

```javascript
function bindPopupInteractions(popup) {
    // 四角缩放：拖某角，对角顶点固定
    popup.querySelectorAll('.mp-resize').forEach(handle => {
        handle.addEventListener('mousedown', (e) => {
            e.preventDefault(); e.stopPropagation();
            const corner = handle.dataset.corner;          // nw|ne|sw|se
            const startX = e.clientX, startY = e.clientY;
            const startRect = popup.getBoundingClientRect();

            const onMove = (ev) => {
                let w = startRect.width, h = startRect.height;
                let left = startRect.left, top = startRect.top;
                if (corner.includes('e')) w = Math.max(200, startRect.width + (ev.clientX - startX));
                if (corner.includes('s')) h = Math.max(150, startRect.height + (ev.clientY - startY));
                if (corner.includes('w')) {
                    w = Math.max(200, startRect.width - (ev.clientX - startX));
                    left = startRect.left + (startRect.width - w);   // 右侧固定
                }
                if (corner.includes('n')) {
                    h = Math.max(150, startRect.height - (ev.clientY - startY));
                    top = startRect.top + (startRect.height - h);    // 下侧固定
                }
                popup.style.width = w + 'px';
                popup.style.height = h + 'px';
                popup.style.left = left + 'px';
                popup.style.top = top + 'px';
            };
            const onUp = () => {
                document.removeEventListener('mousemove', onMove);
                document.removeEventListener('mouseup', onUp);
                savePopupSize(popup.offsetWidth, popup.offsetHeight);
            };
            document.addEventListener('mousemove', onMove);
            document.addEventListener('mouseup', onUp);
        });
    });

    // pin（固定不随 mouseleave 消失，方便对照）
    popup.querySelector('.mp-pin').addEventListener('click', (e) => {
        e.stopPropagation();
        isPinned = !isPinned;
        e.target.textContent = isPinned ? '📌(固定)' : '📌';
    });
    // close
    popup.querySelector('.mp-close').addEventListener('click', (e) => {
        e.stopPropagation();
        isPinned = false;
        hidePopup();
    });
}
```

> **与 3D 渲染的事件分层**（[08](08_富媒体渲染器矩阵.md)）：3D 的 OrbitControls 监听 canvas mousedown 旋转模型；popup 四角 handle 监听 handle mousedown 缩放。handle 的 `stopPropagation` 确保互不干扰。

## 尺寸记忆（全局单一尺寸）

```javascript
const SIZE_KEY = 'mp.popupSize';
function savePopupSize(w, h) { localStorage.setItem(SIZE_KEY, JSON.stringify({ w, h })); }
function loadPopupSize(popup) {
    const saved = localStorage.getItem(SIZE_KEY);
    if (!saved) return;
    try {
        const { w, h } = JSON.parse(saved);
        popup.style.width = w + 'px'; popup.style.height = h + 'px';
    } catch {}
}
```

> **决策**（[11 F3](11_rejected-by-design清单.md)）：只记一个全局 popup 尺寸（缩放结果持久化），不做"每类型/每文件分别记忆"的复杂分级。VSCode Renderer 的 `localStorage` 会话间持久（同源 + Chromium AppData），需 Spike 验证 VSCode 更新后是否被清。

## 图片渲染（v0.1，createElement）

```javascript
async function renderImage(filePath) {
    const resp = await fetch(`${SERVER_BASE}/preview?file=${encodeURIComponent(filePath)}&type=image`);
    if (!resp.ok) throw new Error('server ' + resp.status);
    const data = await resp.json();               // { mime, base64 }
    const content = document.querySelector('.mp-content');
    const img = document.createElement('img');
    img.src = `data:${data.mime};base64,${data.base64}`;
    img.alt = filePath;
    content.replaceChildren(img);                 // createElement，非 innerHTML（TT）
}
```

> **v0.1 图片也须先过 CSP connect-src + TT 两关**（并入 [10 Spike 1/6](10_风险登记册与spike验证.md)）。`data:` URI 在 `img-src` 白名单内 → 拿到 base64 后 `<img src=data:...>` 渲染不需额外 patch img-src（图片是所有类型里相对轻量的）。

## hidePopup + dispose

```javascript
function hidePopup() {
    const popup = document.getElementById('mp-popup');
    if (!popup) return;
    // dispose 富媒体资源（3D rAF/video URL 等，[08](08_富媒体渲染器矩阵.md)）
    if (typeof dispose3D === 'function') dispose3D();
    popup.style.display = 'none';
    const content = popup.querySelector('.mp-content');
    content.replaceChildren();                    // 清空，防泄漏
}
```

## 错误处理

| 场景 | 处理 |
|---|---|
| 文件不存在 | popup 内显 "File not found"（createElement 文本节点） |
| 文件过大（超 [04 MAX_FILE_SIZE](04_EH与Renderer通信协议.md)） | "File too large for preview" |
| EH server 无响应 | "Preview server unavailable" |
| 不支持的类型 | 不弹 popup |
| Trusted Types 拦截（开发期未 createElement） | DevTools Console 报错 → 检查是否误用 innerHTML |
